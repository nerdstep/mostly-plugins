# Mostly plugins

Plugins that connect AI assistants to [Mostly](https://mostly.global) apps.
Each folder is one plugin, listed in Anthropic's Claude directory.

| Plugin | What it does |
| --- | --- |
| [`mostly-recipes`](mostly-recipes/) | Save recipes from your conversations to your [Mostly Recipes](https://mostly.recipes) cookbook, and reopen the ones Claude saved. |

These folders are generated from the Mostly apps' source and published here.
Please report problems through each app's support page rather than by pull
request; changes made here are overwritten by the next release.
